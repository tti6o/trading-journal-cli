# 技术分析系统详解

## 系统概述

交易日志系统的技术分析模块采用模块化设计，集成了多种经典技术指标，能够自动分析交易对并生成交易信号。

## 核心架构

### 4层技术分析架构（第六版优化）

1. **命令接口层** (`main.py:analyze()`)
   - 用户命令入口：`python main.py analyze`
   - 系统状态检查和配置加载
   - 友好的结果展示和操作建议

2. **信号引擎层** (`services/signal_engine.py`)
   - 批量监控币种管理和K线数据获取
   - RSI和斐波那契分析器协调
   - 信号整合和置信度计算

3. **技术分析核心层** (`services/technical_analysis.py`)
   - **RsiAnalyzer**：14期RSI计算和超买超卖信号识别
   - **FibonacciAnalyzer**：关键高低点识别和回调/扩展分析
   - **MarketAnalyzer**：市场分析器统一接口

4. **支持服务层**
   - **专业图表生成** (`services/chart_professional.py`)：基于mplfinance的TradingView风格图表
   - **简化邮件服务** (`services/simple_email.py`)：基于yagmail的HTML邮件通知
   - **数据获取** (`exchange_client/binance_client.py`)：币安API集成和K线数据获取

## 技术指标详解

### 1. RSI (相对强弱指标)

**计算原理**：
- 基于14期价格变化计算
- 范围：0-100
- 数学公式：RSI = 100 - (100 / (1 + RS))
- RS = 平均上涨幅度 / 平均下跌幅度

**信号规则**：
- RSI > 70：超买信号，考虑卖出
- RSI < 30：超卖信号，考虑买入
- RSI背离：价格与RSI走势相反时的反转信号

**代码实现**：
```python
def calculate_rsi(self, prices, period=14):
    """计算RSI指标"""
    deltas = np.diff(prices)
    gains = np.where(deltas > 0, deltas, 0)
    losses = np.where(deltas < 0, -deltas, 0)

    avg_gains = np.convolve(gains, np.ones(period)/period, mode='valid')
    avg_losses = np.convolve(losses, np.ones(period)/period, mode='valid')

    rs = avg_gains / avg_losses
    rsi = 100 - (100 / (1 + rs))
    return rsi
```

### 2. 斐波那契回调/扩展（核心技术指标）

**核心比例**：
- 回调位：23.6%、38.2%、50.0%、61.8%、78.6%
- 扩展位：127.2%、161.8%、261.8%

**应用场景**：
- 趋势回调的支撑阻力位预测
- 价格目标位设定
- 风险管理点位确定

**实现特色**：
```python
def calculate_fibonacci_levels(self, high, low, trend='uptrend'):
    """计算斐波那契水平"""
    diff = high - low
    levels = {}

    fibonacci_ratios = [0, 0.236, 0.382, 0.5, 0.618, 0.786, 1]
    extension_ratios = [1.272, 1.618, 2.618]

    if trend == 'uptrend':
        for ratio in fibonacci_ratios:
            levels[f'{ratio*100:.1f}%'] = high - (diff * ratio)
        for ratio in extension_ratios:
            levels[f'{ratio*100:.1f}% ext'] = high + (diff * (ratio - 1))

    return levels
```

## 信号生成流程（第六版架构）

1. **系统检查**：检查配置文件和监控币种设置
2. **数据获取**：批量获取监控币种的1h K线数据（200根）
3. **技术分析**：并行执行RSI分析和斐波那契分析
   - **RSI分析器**：计算14期RSI，识别超买超卖信号
   - **斐波那契分析器**：识别关键高低点，计算回调/扩展水平
4. **信号整合**：综合评估RSI和斐波那契信号，生成综合信号
5. **置信度计算**：基于多指标一致性计算信号置信度
6. **结果展示**：显示系统状态、市场概览和重点关注币种
7. **专业图表生成**：使用mplfinance生成TradingView风格图表
8. **邮件通知**：基于yagmail框架发送HTML格式邮件通知

## 信号强度评级（新版本）

- **BUY信号**：RSI超卖或斐波那契关键支撑位
- **SELL信号**：RSI超买或斐波那契关键阻力位
- **NEUTRAL信号**：指标处于中性区域或无明确方向
- **置信度评级**：0.0-1.0，基于价格接近度和水平重要性

可以在 `SignalEngine` 类中修改信号生成逻辑：

```python
def evaluate_signals(self, indicators):
    """自定义信号评估逻辑"""
    signals = []

    # RSI信号
    if indicators['rsi'] > 70:
        signals.append(('SELL', 'RSI超买', 0.8))
    elif indicators['rsi'] < 30:
        signals.append(('BUY', 'RSI超卖', 0.8))

    # MACD信号
    if indicators['macd_signal'] == 'golden_cross':
        signals.append(('BUY', 'MACD金叉', 0.7))

    return signals
```
