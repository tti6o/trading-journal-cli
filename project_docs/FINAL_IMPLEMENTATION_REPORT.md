## 🚀 使用方法

### 启动完整系统
```bash
python main.py scheduler start
```

### 手动执行技术分析
```bash

python main.py technical run

# 执行分析并发送邮件通知
python main.py technical notify
```

# 调度器状态

python main.py technical status
