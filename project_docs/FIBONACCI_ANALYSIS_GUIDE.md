# 斐波那契技术分析功能指南

## 📊 功能概述

斐波那契回调和扩展线是技术分析中重要的工具，用于识别：
- **支撑和阻力位**：价格可能反转的关键水平
- **获利目标**：扩展线提供的价格目标
- **入场时机**：回调位提供的买入/卖出机会

## 🎯 核心特性

### 1. 斐波那契回调 (Fibonacci Retracement)
- **关键水平**：23.6%, 38.2%, 50%, 61.8%, 78.6%
- **应用场景**：趋势中的回调，寻找支撑/阻力位
- **信号类型**：在关键水平附近生成买入/卖出信号

### 2. 斐波那契扩展 (Fibonacci Extension) 
- **关键水平**：127.2%, 161.8%, 261.8%
- **应用场景**：突破后的价格目标预测
- **信号类型**：到达目标位时的获利了结信号

## ⚙️ 配置参数

在 `config/config.ini` 中配置斐波那契分析参数：

```ini
[fibonacci]
# 启用斐波那契分析
enabled = true
# 寻找高低点的回看周期 (建议15-25)
lookback_period = 20
# 最小价格变化百分比 (过滤噪音, 建议0.03-0.08)
min_price_change_pct = 0.05
# 价格接近斐波那契水平的阈值 (建议0.01-0.03)
proximity_threshold_pct = 0.02
```

### 参数说明

| 参数 | 默认值 | 说明 | 调优建议 |
|------|--------|------|----------|
| `lookback_period` | 20 | 识别高低点的窗口期 | 较大值识别主要趋势，较小值识别短期波动 |
| `min_price_change_pct` | 0.05 | 过滤小幅波动的阈值 | 增大减少噪音，减小提高灵敏度 |
| `proximity_threshold_pct` | 0.02 | 价格接近斐波那契水平的容差 | 增大捕获更多信号，减小提高精确度 |

## 🔬 技术原理

### 高低点识别算法
1. 使用滑动窗口检测局部极值
2. 过滤价格变化过小的点位
3. 保留最近的有效关键点

### 斐波那契计算
- **回调**：`fib_price = high - (high - low) × fib_ratio`
- **扩展**：`fib_price = point_b + (point_b - point_a) × fib_ratio`

### 信号生成逻辑
1. 计算当前价格与斐波那契水平的距离
2. 判断是否在阈值范围内
3. 结合趋势方向确定信号类型
4. 评估置信度并生成消息

## 核心思想：从直观绘图到程序量化

交易员在图表上凭直觉绘制斐波那契回撤线时，通常会寻找一个“显而易见的”上升或下降趋势的起点和终点。这个过程依赖于人脑对形态的识别能力。然而，将这个直观的过程转化为计算机可以执行的量化算法，则需要我们将“显而易见”这个模糊概念进行拆解和精确定义。

我们的斐波那契分析算法的核心，就是通过`scipy.signal.find_peaks`函数，将交易员的直观判断量化为两个关键的、可配置的参数：`prominence`（显著性）和`width`（宽度）。

### `prominence`（显著性）：定义转折点的“相对高度”

- **直观概念**: “这个高点/低点是否足够重要，能开启一段新的趋势？”
- **量化实现**: 通过`min_price_change_pct`参数计算得出。它定义了一个波峰必须比周围的波谷高出多少，才能被视为一个有效的转折点。
- **作用**: 过滤掉在横盘震荡中的无意义的小幅波动。它确保我们关注的是价格上真正有意义的反转，而非市场噪音。

### `width`（宽度）：定义转折点的“持续时间”

- **直观概念**: “这个顶部/底部是一个稳定的区域，还是一个瞬间的价格毛刺？”
- **量化实现**: 通过`lookback_period`参数配置。它定义了一个波峰/波谷需要持续多少根K线，才能被认为是有效的。
- **作用**: 过滤掉那些由于单次事件（如新闻发布）导致的、不稳定的一根K线价格尖峰（Price Spike）。它确保我们找到的是一个在时间上得到确认的、形态上更平缓和可靠的转折点。

### 黄金组合：高度 + 宽度 = 高质量转折点

| 参数 | 过滤掉的“坏”高点 | 留下的“好”高点 |
| :--- | :--- | :--- |
| **`prominence`** | 📈 横盘震荡中的无意义小波动 | ⛰️ **价格上有重大意义的**反转 |
| **`width`** | 🌵 单根K线的、不稳定的价格尖峰 | 🏔️ **时间上已形成的**、稳固的顶部/底部 |

通过将这两个维度结合，我们的算法能够以一种系统化、可复现的方式，从复杂的市场数据中识别出那些**既有足够价格变动幅度，又在时间上得到确认**的高质量转-折点（Swing High / Swing Low）。这正是将交易员的直观经验成功量化的关键所在。
