# 技术分析系统详解

## 系统概述

交易日志系统的技术分析模块采用模块化设计，集成了多种经典技术指标，能够自动分析交易对并生成交易信号。

## 核心架构

### 4层技术分析架构

1. **信号引擎层** (`services/signal_engine.py`)
   - 统一的信号管理和调度
   - 交易对监控和批量分析
   - 信号强度评估和汇总

2. **技术分析层** (`services/technical_analysis.py`)
   - 各种技术指标的具体实现
   - K线数据处理和计算
   - 单币种深度分析

3. **通知服务层** (`services/notification.py`)
   - 邮件通知功能
   - 信号格式化和内容生成
   - SMTP配置管理

4. **数据获取层** (`exchange_client/binance_client.py`)
   - 币安API集成
   - K线数据获取
   - 实时价格更新

## 技术指标详解

### 1. RSI (相对强弱指标)

**计算原理**：
- 基于14期价格变化计算
- 范围：0-100
- 数学公式：RSI = 100 - (100 / (1 + RS))
- RS = 平均上涨幅度 / 平均下跌幅度

**信号规则**：
- RSI > 70：超买信号，考虑卖出
- RSI < 30：超卖信号，考虑买入
- RSI背离：价格与RSI走势相反时的反转信号

**代码实现**：
```python
def calculate_rsi(self, prices, period=14):
    """计算RSI指标"""
    deltas = np.diff(prices)
    gains = np.where(deltas > 0, deltas, 0)
    losses = np.where(deltas < 0, -deltas, 0)

    avg_gains = np.convolve(gains, np.ones(period)/period, mode='valid')
    avg_losses = np.convolve(losses, np.ones(period)/period, mode='valid')

    rs = avg_gains / avg_losses
    rsi = 100 - (100 / (1 + rs))
    return rsi
```

### 2. MACD (移动平均收敛发散)

**计算原理**：
- 快线：EMA12 - EMA26
- 信号线：MACD的9期EMA
- 柱状图：MACD - 信号线

**信号规则**：
- 金叉：MACD线上穿信号线，买入信号
- 死叉：MACD线下穿信号线，卖出信号
- 柱状图变化：反映趋势强度变化

### 3. 斐波那契回调/扩展

**核心比例**：
- 回调位：23.6%、38.2%、50.0%、61.8%、78.6%
- 扩展位：127.2%、161.8%、261.8%

**应用场景**：
- 趋势回调的支撑阻力位预测
- 价格目标位设定
- 风险管理点位确定

**实现特色**：
```python
def calculate_fibonacci_levels(self, high, low, trend='uptrend'):
    """计算斐波那契水平"""
    diff = high - low
    levels = {}

    fibonacci_ratios = [0, 0.236, 0.382, 0.5, 0.618, 0.786, 1]
    extension_ratios = [1.272, 1.618, 2.618]

    if trend == 'uptrend':
        for ratio in fibonacci_ratios:
            levels[f'{ratio*100:.1f}%'] = high - (diff * ratio)
        for ratio in extension_ratios:
            levels[f'{ratio*100:.1f}% ext'] = high + (diff * (ratio - 1))

    return levels
```

### 4. 布林带 (Bollinger Bands)

**计算公式**：
- 中轨：20期简单移动平均线
- 上轨：中轨 + 2倍标准差
- 下轨：中轨 - 2倍标准差

**信号规则**：
- 价格触及上轨：可能的卖出信号
- 价格触及下轨：可能的买入信号
- 带宽收窄：波动率降低，可能突破

## 信号生成流程

1. **数据获取**：从币安API获取K线数据
2. **指标计算**：并行计算RSI、MACD、斐波那契、布林带
3. **信号评估**：综合各指标状态生成交易信号
4. **强度计算**：根据多指标一致性评估信号强度
5. **格式化输出**：生成易读的信号报告
6. **邮件通知**：发送信号到指定邮箱

## 信号强度评级

- **强信号**：多个指标同时确认
- **中等信号**：部分指标确认
- **弱信号**：单一指标提示

### 自定义信号规则

可以在 `SignalEngine` 类中修改信号生成逻辑：

```python
def evaluate_signals(self, indicators):
    """自定义信号评估逻辑"""
    signals = []

    # RSI信号
    if indicators['rsi'] > 70:
        signals.append(('SELL', 'RSI超买', 0.8))
    elif indicators['rsi'] < 30:
        signals.append(('BUY', 'RSI超卖', 0.8))

    # MACD信号
    if indicators['macd_signal'] == 'golden_cross':
        signals.append(('BUY', 'MACD金叉', 0.7))

    return signals
```
